## Design Context

### Users

CodeInsights is used by engineering, security and platform teams to inspect SAST results, manage quality gates and administer integrations and access. The interface must support fast, precise operational work on desktop while remaining fully usable on smaller laptops and mobile viewports.

### Brand Personality

Technical, calm and trustworthy. The product should feel like a focused engineering workspace: clear hierarchy, restrained visual treatment, explicit state and no decorative noise.

### Aesthetic Direction

A light, utilitarian interface aligned with the Upcoop blue identity and the tokens in `DESIGN.md`. Prefer flat information hierarchy, compact native controls, readable data tables and progressive disclosure. Avoid stacked navigation rows, redundant headings, nested cards, loud actions and custom controls where a robust accessible HTML control already exists.

### Design Principles

- Make the primary engineering task immediately visible; remove redundant filters, headings and actions.
- Preserve honest information density without crushing content: grids reflow and wide tables scroll as deliberate regions.
- Use native accessible controls with predictable focus, labels and responsive sizing.
- Keep dangerous actions explicit and secondary actions visually quiet.
- Validate key workflows at mobile, tablet and desktop widths before release.
