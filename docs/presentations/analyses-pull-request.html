Constat

Verdict de branche emprunté

Constat

Baseline faussée

En modes version précédente, nombre de jours ou analyse spécifique, un build de PR pouvait devenir la baseline New Code de sa branche source.

Décision

Branche sans build de branche

État vide explicite qui propose ses PR, plutôt qu’un verdict emprunté.

Décision

Vue d'une PR

Overall et New Code, comme une branche.

Option A pour les findings : un build de PR relie ses occurrences aux findings de sa branche source sans les modifier. Rétention des PR fermées décidée à 30 jours, à réaliser (slide 9).
