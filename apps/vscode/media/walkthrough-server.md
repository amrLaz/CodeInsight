# URL du hub

L'extension reste inactive tant que `codeinsights.serverUrl` est vide. Saisir l'URL du hub, sans slash final superflu, par exemple `https://codeinsights.example`.

Le `project_key` n'a pas à être saisi : l'extension le résout depuis l'URL du dépôt, ou depuis `.codeinsights/vscode.json` dans un monorepo.
