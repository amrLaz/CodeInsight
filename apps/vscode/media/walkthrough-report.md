# Rapport de branche

Le panneau **CodeInsights** (à côté de Problèmes) affiche le verdict de la dernière analyse de la branche courante, ses mesures et ses conditions. Une mesure absente reste « Non mesuré », jamais zéro. Une branche sans analyse affiche « aucune analyse », jamais un gate vert.

Les issues sont dans le panneau Problèmes, recalées sur le working tree. La gouttière reprend la couverture de cette analyse ; un LCOV local plus récent peut la remplacer s'il est configuré.
