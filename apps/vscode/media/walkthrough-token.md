# Jeton personnel

Dans le hub, l'avatar de l'appbar ouvre le dialogue **Personal access tokens**. Créer un jeton :

- lecture seule pour consulter le rapport et les issues ;
- scope de collaboration si le traitement (assignation, état, commentaire) se fait depuis l'éditeur.

Le jeton expire. L'extension ne le crée pas, ne le journalise pas et ne le range pas dans les paramètres synchronisés.
